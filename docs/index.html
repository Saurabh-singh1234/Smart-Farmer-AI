Overview

Smart Farmer AI is a Streamlit-based web application that leverages Google Gemini and various AI/ML tools to assist farmers. It provides three core capabilities:

💬 Chat Assistant

Ask agriculture-related questions and get expert answers powered by Gemini 2.5 Flash.

🎤 Voice Interaction

Speak your queries via microphone; speech-to-text converts them to text, and responses are read aloud via text-to-speech.

🌱 Disease Detection

Upload a crop image and receive AI-driven disease analysis with actionable recommendations.

Setup & Installation

Prerequisites

  • Python 3.10+
  • A Google Gemini API key (set as GOOGLE_API_KEY in .env)
  • A Gemini API key for disease detection (set as GEMINI_API_KEY in .env)
  • (Optional) OpenWeather API key for weather tool (OPENWEATHER_API_KEY)
  • (Optional) Working microphone + PyAudio for voice features

Installation Steps

# 1. Clone the repository
git clone <repo-url>
cd Smart-Farmer-AI

# 2. Create and activate a virtual environment
python -m venv venv
.\venv\Scripts\activate   # Windows
source venv/bin/activate  # Linux/macOS

# 3. Install dependencies
pip install -r requirements.txt

# 4. Create .env file with your API keys
echo GOOGLE_API_KEY=your_key_here >> .env
echo GEMINI_API_KEY=your_key_here >> .env

# 5. Run the application
streamlit run app.py

Usage Guide

Chat Tab

Type any agriculture-related question in the chat input. The AI assistant (powered by Gemini 2.5 Flash) will respond with expert advice.

Voice Tab

  1. Click 🎤 Ask by Voice.
  2. Speak your query clearly into the microphone.
  3. The app transcribes your speech, gets an AI response, and plays the answer aloud via TTS.

Disease Detection Tab

  1. Upload a crop image (JPG, JPEG, or PNG).
  2. Click Detect Disease.
  3. View the AI diagnosis and recommendations, with optional audio playback.

models/ — AI Model Wrappers

gemini.py

Python models/gemini.py — 47 lines

Loads GOOGLE_API_KEY from the environment and initializes a ChatGoogleGenerativeAI instance using the gemini-2.5-flash model with temperature 0.7.

Key details:

  • Uses python-dotenv to load .env.
  • Wraps the LLM import in a try/except so missing dependencies don't break app startup.
  • If initialization fails, llm is set to None and a runtime error is surfaced in the chat UI.

translator.py

Python models/translator.py — 9 lines

Exposes a translate_text(text, target) function using the googletrans library. The target parameter is a language code (e.g., 'te' for Telugu).

whisper_model.py

Python models/whisper_model.py — 7 lines

Loads OpenAI Whisper's base model and provides a speech_to_text(audio_path) function that transcribes an audio file.

services/ — Speech Services

speech_service.py

Python services/speech_service.py — 72 lines

Provides two core functions:

speech_to_text(language="en-IN", phrase_time_limit=10) → str

  • Uses speech_recognition with the Google Web Speech API.
  • Calibrates to ambient noise for accuracy.
  • Returns recognized text or raises RuntimeError with user-friendly messages for microphone, recognition, or network failures.

text_to_voice(text, lang="en") → str

  • Converts text to speech using gTTS (Google Text-to-Speech).
  • Saves output to a unique MP3 file (response_<uuid>.mp3) and returns the absolute path.
  • Raises RuntimeError for empty text or TTS failures.

tools/ — Utility Tools

crop_tool.py

Python tools/crop_tool.py — 11 lines

crop_advice(query) returns a static recommendation for wheat, rice, and maize based on the user query. This is a placeholder for future ML-powered recommendations.

disease_tool.py

Python tools/disease_tool.py — 52 lines

Core crop disease detection pipeline:

  1. Validates that the google-generativeai SDK is installed and GEMINI_API_KEY is set.
  2. Converts a PIL Image to PNG bytes for SDK compatibility.
  3. Sends the image to Gemini 2.5 Flash with a prompt asking for crop disease analysis and actionable recommendations.
  4. Returns the model's text response.

weather_tool.py

Python tools/weather_tool.py — 21 lines

get_weather(city) → dict fetches current weather data from the OpenWeatherMap API for the given city. Requires OPENWEATHER_API_KEY in the environment.
